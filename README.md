# Narrating Waste Uncertainty and Invisibility 2.0

Static exhibition edition of the original interaction design research project.

## Contents

The original homepage, artwork, 12 character perspectives, 24 scripted question-and-answer exchanges and external local-story links. No server, build step, database, login or API key is required. AI chat, account features, history, avatar uploads and custom character generation are intentionally excluded. External story images and articles remain hosted by their original publishers.

## Publish on GitHub Pages

In Settings → Pages, choose Deploy from a branch, select `main` and `/ (root)`, then Save.

All local links use relative paths, so the site supports a GitHub project URL and direct navigation to every character page. Preview with `python3 -m http.server 8000`.

This export contains bundled public artwork and source content; it does not contain private conversations, uploaded user images, database records or runtime secrets.

## Scripted conversations
Each character page preserves both original suggested questions and provides newly authored fictional answers based on its persona. The first exchange is visible immediately. Question buttons reveal answers; restart clears the dialogue. These are not recovered user conversations, live AI responses or verified accounts of actual events. All answers work offline without a backend.
